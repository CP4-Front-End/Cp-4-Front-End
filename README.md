# D-Wall EcoLoop – E-commerce Sustentável

## Descrição do Projeto
Este repositório contém o desenvolvimento do **D-Wall EcoLoop**, um projeto acadêmico de front-end com proposta de e-commerce voltado para produtos sustentáveis e ecológicos.

A ideia do projeto é unir **consumo consciente**, **identidade visual moderna** e **navegação intuitiva**, apresentando uma loja virtual com categorias de produtos como **roupas**, **beleza**, **tecnologia** e **casa**.

O site foi desenvolvido com foco em **estrutura semântica**, **responsividade** e uso de componentes do **Bootstrap**, simulando a experiência inicial de uma loja online real.

## Objetivo
O principal objetivo deste projeto foi aplicar, na prática, conceitos de desenvolvimento front-end, incluindo:

- Estruturação de páginas com **HTML5**
- Estilização com **CSS3**
- Uso de **Bootstrap**
- Criação de layout **responsivo**
- Navegação entre páginas
- Organização visual de produtos em um e-commerce fictício

---

## Funcionalidades do Projeto
O projeto conta com as seguintes páginas e recursos:

- **Página inicial (`index.html`)**
  - Navbar fixa no topo
  - Carrossel com imagens de destaque
  - Seções organizadas por categorias:
    - Roupas
    - Beleza
    - Tecnologia
    - Casa
  - Cards de produtos com botão de compra
  - Navegação por âncoras para seções da própria página

- **Página de produto (`produto.html`)**
  - Exibição individual do produto
  - Nome, imagem, preço e descrição
  - Botão de compra
  - Layout adaptado para diferentes tamanhos de tela

- **Página de carrinho (`carrinho.html`)**
  - Mensagem de carrinho vazio
  - Botão para retornar à página inicial
  - Estrutura pensada para simular a experiência de e-commerce

- **Página de contato (`contato.html`)**
  - Formulário de contato
  - Campos para nome, sobrenome, endereço, país, estado e preferências de contato
  - Estilização personalizada com Bootstrap e CSS próprio

## Responsividade

## Identidade Visual

A identidade visual do projeto foi construída para reforçar a proposta sustentável da marca **D-Wall EcoLoop**, utilizando:

* tons de **cinza** para base visual
* **amarelo** como cor de destaque e ação
* elementos visuais com estilo moderno e urbano
* logo própria aplicada na navegação e identidade da loja

Essa combinação busca transmitir uma estética de marca contemporânea, ecológica e tecnológica.
